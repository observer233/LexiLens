# LexiLens v0.2.0 · 更容易上手的 AI 平台接入

下载 `LexiLens-v0.2.0-win-x64.zip`，解压运行 `LexiLens.exe`。自带 .NET 运行时；需要 Windows x64、对应 OCR 语言功能，建议 Windows 11。

## 新增

- 首次启动的服务向导：直接试用、本地离线、使用自己的 AI 平台额度。
- 24 个云平台预设，附官方获取密钥与文档入口；另有自定义兼容服务。
- 默认显示免费档候选，其余试用/赠送/付费平台单独显示；未核验选择需确认额度。
- Gemini、Anthropic 原生协议及其他平台的 Chat Completions 接入，读取账号模型列表。
- 「仅测试连接」「测试并使用」，显示固定测试句译文和耗时。
- Windows 当前账号加密保存密钥，按平台和地址隔离，可清除。
- Ollama 本机检测、读取模型、下载推荐 `qwen2.5:3b` 的按钮。
- 限流冷却、余额和密钥错误提示；不自动切换平台或付费模型。

## 如何使用

没有账号：保持「直接试用」，测试后框选游戏文字并开始。

已有智谱等额度：选择平台 → 打开官方领钥匙页面 → 粘贴自己的标准 API Key → 选模型 → 测试并使用。多数平台仍需要用户自行注册、实名或领取额度。

## 验证与限制

55 项自动测试通过，桌面诊断通过向导交互、密钥加密、真实截图/OCR/MyMemory 翻译。24 个平台的协议请求经过模拟测试；由于没有各平台用户 Key，没有逐个真实账号验证，不承诺所有账号或地区可用。

有免费档不等于保证账单为零。已启用计费的账号可能收费，限时额度可能到期；请在平台控制台设置用完即停。软件不捆绑公共 API Key、不代注册，不能凭空获得个人额度。完整政策与条件见仓库 `docs/AI_PLATFORMS.md`。

保留英中对照、鼠标穿透、生词本及 CSV 导出。仍为早期原型，建议游戏无边框窗口模式；未完成各游戏、HDR、混合 DPI 兼容矩阵，发布包尚未签名。
