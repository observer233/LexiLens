# LexiLens v0.5.1 · 快速字幕、多区域独立悬浮框、对白回看

下载 `LexiLens-v0.5.1-win-x64.zip`，退出旧版、完整解压后运行 `LexiLens.exe`。Windows x64，自带 .NET 与 OCR 模型，原设置/密钥/生词保留；旧版单选区会迁移。

v0.5.1 同时补充关闭单个悬浮框后的区域隔离，避免该区域后续结果写入其他区域。

## 更快提交字幕

- 默认开启“快速字幕”，每 150ms 独立采样，系统 OCR 优先、空结果增强回退，首次识别即发翻译。
- 扫描间隔包含识别耗时，避免识别完再等整轮间隔。
- 共享缓存和最多两条并行翻译；快速模式云端起始间隔默认 400ms，可按账号限制调整，429 冷却保留。
- 新字幕不取消已捕获的上一句；晚到的旧结果不会覆盖新译文。清晰优先模式仍可用于特殊字体。

## 多选区，分开显示

“添加框选”或 **Ctrl+Alt+A** 继续添加，最多四区。每个区域有自己的原文/译文和悬浮框，可命名、重选、移除。框初始放在选区旁，尽量避开已有框；解锁可拖动/调整宽度，停止或退出保存位置。

区域下拉框切换当前原文/译文，日志带区域编号。H 显隐全部框，L 切换全部穿透（均加 Ctrl+Alt）。添加/编辑区域会停止当前会话，完成后重新开始。

## 对白回看

左侧保留最近 100 条完成的原文/译文，按提交时间排列，仅在本次打开期间保留，可清空。练习窗口新增 0.8 秒/句自动对白，可测试所选服务能否跟上。

## 验证和边界

80 项核心测试通过；桌面诊断验证实际截图/OCR/MyMemory、两个独立区域和模拟不同译文、区域切换、独立悬浮框、位置保存、回看、超时恢复和报告导出。固定练习字幕一次快速读取约 14ms，仅为本机截图/OCR 样本，不含 API 生成。

队列有界；处理速度落后会显示 `CAPTURE_BACKLOG` / `SUBTITLE_QUEUE_FULL`。未采样到的瞬间字幕无法恢复，公网速度取决于模型和网络，快速模式对特殊字体可能不如清晰优先准确。四个大区域也会增加资源消耗。

本版采用手动多框方案，整窗自动语义聚类未实现；固定选区不跟随窗口移动或缩放。商业游戏、HDR、混合 DPI、长期占用及各平台真实账号仍需进一步验证。
