# LexiLens v0.1.0 · 游戏里的语言伙伴

首个 Windows 可用原型：保留游戏的英语环境，在外部悬浮窗中阅读中文对照，并收藏不熟悉的单词。

## 使用

下载 `LexiLens-v0.1.0-win-x64.zip`，解压运行 `LexiLens.exe`。需要 Windows 10 build 19041 或更高版本（建议 Windows 11）、x64，以及英语 Windows OCR 功能。压缩包自带 .NET 运行时。

先打开练习场，框选英文任务句，再开始翻译。游戏建议使用无边框窗口模式。

- `Ctrl+Alt+T`：开始/暂停。
- `Ctrl+Alt+R`：重新框选。
- `Ctrl+Alt+H`：显示/隐藏悬浮窗。
- `Ctrl+Alt+L`：切换鼠标穿透；解锁后可以点击英文查词。

## 功能

本地截图与 Windows OCR、英中对照悬浮窗、鼠标穿透、稳定识别与重复缓存、新字幕取消旧请求、MyMemory 免密钥翻译、Ollama 接口、生词收藏及 CSV 导出。

## 已验证与边界

15 项核心自动测试通过，已在 Windows 练习窗口跑通真实截图 → OCR → MyMemory 翻译，并验证悬浮窗穿透。Ollama 接口经过协议测试，实际模型仍待验证。

默认 MyMemory 会接收识别文字，具有额度限制，不适合无限高频调用；截图留在本机。使用本机 Ollama 地址可离线翻译，但需自行安装服务和下载模型。

当前是早期原型，不保证所有游戏、独占全屏、HDR 或混合 DPI 环境可用。定时 OCR 与翻译服务会产生延迟，快速消失或复杂字体的字幕可能识别失败。界面「示例预览」是固定演示，开始会话后才是真实识别。
