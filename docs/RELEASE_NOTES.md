# LexiLens v0.6.0 · 游戏内划选即译、自动分段与原位覆盖

下载 `LexiLens-v0.6.0-win-x64.zip`，退出旧版、完整解压运行 `LexiLens.exe`。原有密钥、服务设置、生词、固定选区保留；显示方式默认升级为“原位覆盖”。

## 游戏内操作

- **Ctrl+Alt+Q**：拖选临时区域，松手自动识别翻译；主窗口保持最小化，尝试把焦点交还之前的游戏窗口。
- 临时区默认持续跟译，取消“临时区连续跟译”可只翻译当前画面。**X** 清除，**M** 打开主窗口（均加 Ctrl+Alt）。
- **Ctrl+Alt+A / R / W**：添加固定区 / 重选当前固定区 / 吸附选窗口；选完自动开始。Esc 取消保留原状态，临时区不改动固定区配置。

## 三种显示方式

**原位覆盖（默认）**保留 OCR 位置，按基线、行距、字号与横向距离自动分段，在原文处显示半透明译文。**旁置分段**把每块译文放在原文附近。**固定悬浮**保留旧版每区合并、拖动、查词与位置保存。**Ctrl+Alt+V** 切换。

重叠固定区以文字中心归属较小的选区；临时区优先，清除后恢复固定显示。文字改变/消失后撤下旧框，晚返回的旧译文只进回看，不重新盖到新画面上。连续定位两秒无新帧也会撤层，避免引擎卡死时残留旧覆盖。

快速自动分段使用 Windows OCR，空结果直接撤层；特殊字体可取消快速模式，用增强引擎。Windows/Paddle 均保留定位信息。修复了词框上下伸部高度不同导致一句被拆成多块的问题。

## 验证与边界

90 项核心测试通过；真实桌面练习验证原位层、自动分段、空画面撤层、自动划选翻译、焦点返回、Esc 保留、重叠归属和固定区自动开始，另保留实际 OCR/MyMemory 与故障回退验证。定位译文使用模拟服务，未使用用户真实 Key。

每区默认最多 12 块，可调 4–24；超量或积压会记录 BLOCK_LIMIT / BLOCK_QUEUE_FULL。分段基于几何关系，复杂排版/花体仍可能误分；小框内过长译文可能截断，回看保留全文。固定区不跟随窗口移动/缩放。游戏独占全屏、焦点策略和快捷键冲突需按游戏验证；不能保证所有瞬间字幕或公网响应速度。
