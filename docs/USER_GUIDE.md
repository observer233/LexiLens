# 使用指南

## 第一次使用

1. 解压下载包，运行 `LexiLens.exe`。
2. 点击引导中的“选择服务”。智谱用户选择“AI 平台”→“智谱”→粘贴标准 API Key→选择免费候选 `glm-4.5-flash`→“测试并保存”。没有密钥可使用 MyMemory。
3. 点击“选择窗口”，把鼠标移到游戏窗口上，出现蓝色边框后单击。Esc 取消。也可选择“手动框选”，仅截取任务或字幕。
4. 点击“翻译一次”。左边应先出现识别原文，右边随后显示译文。
5. 单次正常后，再“开始连续翻译”。

首次引导可收起，左侧“使用引导”可再次打开。主界面不预填演示译文；“预览悬浮窗”才使用明确标记的固定示例。

## 选择窗口

“选择窗口”按可见窗口的边缘吸附，不需要拖出矩形。它选的是窗口可见范围；窗口移动、缩放后要重新选择，跨屏窗口取单一显示器上最大的可见部分。想只翻译对话时，手动框选可以减少 OCR 耗时和 API 消耗。

快捷键均为 Ctrl+Alt 加以下字母：W 选窗口，R 框选，F 翻译一次，T 开始/停止，H 显隐悬浮窗，L 切换鼠标穿透；A 添加框选。快捷键被占用时会提示，可继续使用按钮。

## 多个区域，分开显示

点击“添加框选”（Ctrl+Alt+A）继续选择字幕、任务栏等区域，最多 4 个。每个区域独立识别并显示在自己的悬浮框，原文不会跨区合并。下拉框切换当前区域，输入名称后点“命名”；“手动框选”/“选择窗口”重选当前区域，“移除区域”删除当前区域。添加、重选、删除和命名会停止当前会话，完成后重新开始。

悬浮框默认放在对应选区旁，空间允许时避开已有框。Ctrl+Alt+L 解锁全部悬浮框，拖动顶部、调整宽度后再锁定。停止/退出时保存位置。窗口移动、屏幕布局改变后需要重选。整窗内的语义自动分组尚未加入。

## 快速字幕和对白回看

主界面勾选“快速字幕”：每 150ms 采样，优先 Windows OCR，空结果再尝试增强引擎；首次识别立即请求翻译。识别和翻译分别有有界队列，较新的字幕不会取消已捕获的上一句。字幕消失后保留最近译文，完成的原文/译文进入“对白回看”，按捕获时间排列，最多 100 条，只在本次打开期间保留，可手动清空。

如果特殊字体认错，取消快速字幕，使用“设置”里的增强 OCR 与图像处理。清晰优先会确认近似结果两次，持续变化三次则提交，三个空结果清空显示。

多个区域共用最多 2 个翻译请求，快速模式 API 最小间隔默认 400ms，可在设置调整为 200–5000ms。间隔越短可能越快触及平台限额；HTTP 429 会冷却，不自动换服务。采样帧队列只保留最近 2 帧，每区待译队列最多 8 条；处理速度落后时会明确记录 `CAPTURE_BACKLOG` / `SUBTITLE_QUEUE_FULL`，避免无限积压。

“练习窗口”可开启 0.8 秒/句的自动对白，测试实际服务能否跟上。未采样到的画面无法恢复，云端生成译文需要额外时间；[速度说明](PERFORMANCE.md)。

## 判断卡在哪一步

| 步骤 | 正常状态 | 卡住或报错时看什么 |
| --- | --- | --- |
| 截图 | 完成，记录选区大小 | 近乎全黑、区域越界、窗口遮挡、全屏捕获限制 |
| 文字识别 | 显示原文、字符数和耗时 | 增强进程超时、缺运行库、空结果；可以“检查识别”或改用 Windows OCR |
| 文字判断 | 已确认 / 未变化 | 连续模式会确认文字，容忍少量误字；单次翻译直接提交 |
| 翻译服务 | 请求已发送 → HTTP 状态 → 完成 | 401 密钥，403 权限/地区，402 余额，429 限流，404 模型/地址；不再统称为等待识别 |
| 悬浮显示 | 完成 | 检查悬浮窗是否隐藏、是否被游戏覆盖 |

“仅测试连接”发送固定句子，不经过屏幕 OCR。连接测试成功而游戏无译文时，先看截图和识别步骤。

快速模式首次识别即提交；清晰优先确认后提交。两种模式都会跳过重复文字，数字变化不会被当作相同结果。

## 诊断与日志

点击左侧“诊断与日志”，查看每步的时间、状态、耗时和错误代码。

- “测试翻译服务”：只测当前服务的固定短句。
- “检查识别”：查看当前选区截图和原始 OCR，不请求翻译。
- “改用 Windows OCR”：停止当前会话，切换引擎并保存；随后可再翻译一次。
- “导出诊断报告”：导出 JSON，可用于提交问题。

报告包含最近最多 500 条事件、系统与模型配置摘要，不包含密钥、服务地址、窗口标题、游戏原文和截图。日志自动写入 `%LOCALAPPDATA%\LexiLens\logs\pipeline.jsonl`，约 1 MB 轮换，最多保留约 4 MB；重启后仍可读取最近记录。

## 识别设置

增强识别已内置英文/中文模型，在独立 CPU 子进程运行。首次最多等待 15 秒，后续 8 秒；超时会终止该子进程，并在有系统 OCR 时切换。增强结果为空也会尝试 Windows OCR。

图像处理可选自动、原图、暗底亮字和低对比度。更改后点击“保存设置”，重新检查。其他语言或选择 Windows 引擎时，需安装相应 Windows OCR 语言功能。缺少 VC++ x64 时可打开设置中的微软安装说明。

## 悬浮窗和生词

开始时悬浮窗自动穿透鼠标。Ctrl+Alt+L 解锁后可拖动窗体、调整大小或点击英文单词。查词可编辑释义后收藏，也能在生词本手动输入单词。CSV 导出字段为 Word、Meaning、Context、AddedAt。

Ctrl+Alt+H 只隐藏悬浮窗，不停止识别或请求；Ctrl+Alt+T 才停止会话。

## 本地翻译

设置翻译服务为 Ollama，先安装 Ollama，再读取本机模型或点击下载推荐 `qwen2.5:3b`。OCR 模型与翻译模型不同，前者已内置，后者约 1.9 GB，需要首次下载。使用本机地址时可离线，远程地址会接收识别文字。

## 本地文件

设置、生词和加密密钥位于 `%LOCALAPPDATA%\LexiLens`；日志在其中的 `logs`。升级可直接退出旧版、解压新版运行，原有数据继续使用。不要把整个数据目录当作问题报告上传；使用应用里的诊断导出即可。
