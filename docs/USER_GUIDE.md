# 使用指南

## 第一次启动

下载 Release 压缩包并解压，运行 `LexiLens.exe`。无需安装 .NET 或申请翻译密钥。

v0.2.0 首次打开会显示翻译服务向导。想直接使用，选择「直接试用」并点击「测试并使用」；已有智谱等额度，选择自己的平台、粘贴标准 API Key 后测试。主界面右侧「选平台 / 接入免费额度」可以随时重新配置。完整说明见 [AI 平台接入](AI_PLATFORMS.md)。

主界面初始显示的是带有「示例预览」标记的固定英文和中文。点击「预览悬浮窗」可以检查显示效果并体验内置词汇查词；它不会开始截图或联网翻译。

在「偏好设置」中，默认识别语言为 `en-US`。翻译服务通过向导配置，默认 MyMemory。使用 MyMemory 时，开始后的识别文字将发送至该第三方服务，截图留在本机。

## 检查 OCR 语言包

进入 Windows 设置 → 时间和语言 → 语言和区域，添加英语（美国），安装语言选项中的「光学字符识别」。具体入口名称可能随 Windows 版本不同而变化。

重新启动 LexiLens。偏好设置中的识别语言列表来自 Windows 已安装的 OCR 语言；未安装的默认英语会标记为「未安装 OCR」。缺少语言包时，开始按钮会显示说明，不会静默切换为其他语言。

## 先在练习场跑通

1. 点击左侧「打开练习场」。
2. 回到 LexiLens 点击「框选区域」，或使用 `Ctrl+Alt+R`。LexiLens 主窗口和悬浮窗暂时隐藏，每块显示器显示框选层。
3. 在练习场上拖动，选中白色英文任务句。尽量只选文字；按 `Esc` 可取消。
4. 点击「开始翻译」或按 `Ctrl+Alt+T`。约两次稳定扫描后提交翻译，响应后显示中文。
5. 点击练习场的「下一句」，检查悬浮窗是否更新。
6. 按 `Ctrl+Alt+T` 暂停，确认停止后的译文标记为「已暂停」。

## 在游戏里使用

把游戏设为无边框窗口或窗口模式，让任务或对话字幕显示出来，再框选文字区域。窗口移动、字幕位置改变或游戏分辨率改变后需重新框选。

开始时悬浮窗自动进入鼠标穿透状态，游戏仍能收到点击。使用 `Ctrl+Alt+L` 解锁，可拖动顶部移动窗体、拖动边缘改变大小、点击英文查词；操作完成后再锁定。

`Ctrl+Alt+H` 只改变悬浮窗显隐，识别和网络请求仍继续。要停止识别与请求，使用 `Ctrl+Alt+T`。关闭主窗口会停止会话并退出应用。

若 `Ctrl+Alt+R` 等快捷键被录屏软件或显卡工具占用，主窗口会提示冲突；仍可使用按钮操作。第一版未提供快捷键修改界面。

## 收藏与导出生词

解锁悬浮窗后点击英文单词。内置词汇直接显示简短释义；其他词汇通过当前翻译服务查询。可以手动编辑释义，点击「收藏到生词本」保存单词及当时的原句。

也可以在「我的生词本」输入英文单词手动查词。重复收藏会更新同一单词的释义、原句和收藏时间。固定示例中收藏的原句带 `[示例]` 前缀。

「导出 CSV」会导出 `Word, Meaning, Context, AddedAt` 四列，使用带 BOM 的 UTF-8 编码。可在 Anki 中导入并自行映射字段；这不是带发音或牌组设置的 `.apkg` 文件。

## 使用本地 Ollama

1. 先按 [Ollama 文档](https://docs.ollama.com/quickstart) 安装并运行服务。
2. 下载一个适合中英翻译且能在本机运行的模型，例如 `ollama pull qwen2.5:3b`。模型文件不包含在本应用中，首次下载需要网络。
3. 在 LexiLens 翻译服务向导中选择「本地离线」。点击「检测并读取本机模型」；也可点击「下载推荐 3B 模型」，无需手动命令。
4. 选择实际已下载的模型名；本机地址默认 `http://localhost:11434`，一般不需要修改。
5. 点击「测试并使用」，重新开始翻译。第一次模型加载可能较慢，请按硬件情况使用较小模型。

本机 loopback 地址可使用 HTTP。远程服务地址必须使用 HTTPS，文字会发送到所填服务器，不再是本地离线模式。Ollama 原生入口不支持认证头；需要 Bearer Key 的兼容网关可用自定义兼容服务入口，其他特殊签名不支持。

## 常见问题

| 情况 | 建议 |
| --- | --- |
| 提示未安装 OCR | 安装对应 Windows OCR 语言功能后重启应用 |
| 黑屏、无字幕或悬浮窗不显示 | 改为无边框窗口；缩小到任务/字幕区域；确认画面不是受保护内容 |
| 文字始终在变或识别不稳定 | 提高游戏字号，避免动画区域，等待文字完整显示 |
| 翻译报错或不再更新 | 查看主窗口错误提示；检查网络、MyMemory 额度或 Ollama 服务；暂停后重新开始 |
| 设置改了但没有生效 | 点击「保存设置」，再重新开始会话 |
| 旧字幕没有立刻消失 | 连续三次识别为空才会清空；暂停时刻意保留最后结果并标记状态 |
| 无法点击悬浮窗 | 按 `Ctrl+Alt+L` 解锁鼠标穿透 |
| 悬浮窗被识别进去了 | 将悬浮窗移到框选区域外；检查主窗口是否提示截图排除失败 |
| 多屏缩放后框选不准 | 在单一显示器内重新框选，屏幕配置改变后重启应用；混合 DPI 尚待更多验证 |

## 本地数据

数据目录：`%LOCALAPPDATA%\LexiLens`。

- `settings.json`：翻译服务、OCR 语言、扫描间隔、悬浮显示及区域。
- `credentials.dat`：按当前 Windows 账号加密的密钥库。换电脑或账号后需重新填写，普通设置中不包含明文 Key。
- `vocabulary.json`：主动收藏的词汇、释义和原句。
- 文件损坏时保留 `.corrupt-*` 副本，便于恢复。

退出后可备份此目录。分享问题报告时无需上传这些文件；其中可能包含你的游戏对话或自行配置的服务地址。
