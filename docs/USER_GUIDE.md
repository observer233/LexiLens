# 使用指南

## 游戏内直接翻译

先启动 LexiLens，配置并测试翻译服务。回到游戏后按 **Ctrl+Alt+Q**，拖选需要翻译的文字，松手自动识别翻译。无需回到主窗口点开始。选择结束后尝试把焦点交还之前的游戏窗口，主窗口留在任务栏中最小化；按 **Ctrl+Alt+M** 可打开。

临时划选默认持续跟译当前区域，直到下次划选、Ctrl+Alt+X 清除、停止或退出。取消主界面的“临时区连续跟译”，可改为只翻译本次画面并保留结果。再次 Q 可以换一块。Esc 取消当前划选，原临时结果和固定区域保持原状态。临时区不保存到固定区列表。

固定区适合持续字幕或任务：**Ctrl+Alt+A** 添加（最多四个），**Ctrl+Alt+R** 重选当前固定区，**Ctrl+Alt+W** 吸附选择整个窗口。选完自动开始连续翻译。框选时短暂暂停截图，避免把选区提示识别成游戏内容；已有翻译可以继续完成。修改固定区会自动重启固定识别，取消选择则不停止原会话。

独占全屏游戏可能在外部选区出现时切换/暂停，焦点返回也受游戏与 Windows 限制。当前已验证桌面练习窗口的焦点返回；具体游戏需要实测。

## 三种显示方式

主界面可选择，或在游戏内按 **Ctrl+Alt+V** 循环切换：

| 模式 | 识别与显示 |
| --- | --- |
| 原位覆盖（默认） | 一次 OCR 保留词/行坐标，按距离、行距、字号聚合为文本块，在对应原文位置画半透明框并显示译文 |
| 旁置分段 | 同样自动分段，在各段原文右侧/下方/上方空间显示；空间不够时可能回到原位 |
| 固定悬浮 | 每个选区合并成一个可拖动悬浮框，保留原来的原文点击查词与位置保存 |

“快速字幕”控制识别/提交速度，与显示方式分开。开启后系统 OCR 优先、首次识别即翻译；自动分段模式的空结果立即撤层，避免等待增强回退时残留旧译文；取消后使用所选增强/Windows 引擎并确认文字。两种识别方式都会把坐标交给原位/旁置显示。

自动分段按几何位置判断，不代表已经理解每段是任务、菜单或人物对白。复杂分栏、特殊字体和相邻短标签仍可能错分，缩小固定范围可明确划分。每区默认最多 12 个文本块，设置中可调 4–24；超出记录 `BLOCK_LIMIT`，不会把多余块合并塞进同一个框。

## 位置、归属与旧译文

文字块使用相对坐标映射回实际屏幕，OCR 缩放不会改变最终覆盖位置。同一文字块的小幅位置抖动保留其译文并更新位置；内容变化会清除旧译文，持续跟译时文字消失后撤下框；连续模式超过两秒没有新识别帧也会撤层，防止引擎卡住时旧译文长期遮挡。单次快照按用户选择保留到清除。较晚完成的过期字幕仍可进入回看，但不会盖回已经改变的文字位置。

重叠固定区优先由面积较小的选区负责；相同面积按稳定区域 ID 决定。临时区覆盖的文字中心优先交给临时区，清除临时结果后固定区恢复。这个规则减少整窗区和字幕区同时识别同一处文字的重复框。

原位框随原文字块大小限制高度，自动缩小字号，太长时可能截断；**对白回看**保留全文。Ctrl+Alt+L 解锁后悬停文本块可查看原文/完整译文，右键可再次划选、开始/停止固定区、清除临时译文。默认鼠标穿透，不阻挡游戏操作。原位/旁置模式的框位置跟随 OCR，固定悬浮模式才支持手动拖动与记忆位置。

原位层必须成功排除截图；失败会停止该区域并提示使用固定悬浮，防止 OCR 识别自己的中文译文。

## 快捷键

全部使用 Ctrl+Alt：Q 临时划选，A 添加固定区，R 重选当前区，W 选窗口，V 切换显示方式，X 清除临时，M 主窗口，T 开始/停止，F 固定区单次翻译，H 显隐译文层，L 穿透/解锁。快捷键冲突可在主窗口看到提示，仍可用界面按钮。

H 只隐藏显示，识别和请求仍继续；T 才停止。原位与旁置之间可直接切换；涉及固定悬浮时会重建识别流程，在原固定区运行时自动恢复，并用原临时选区重新识别。

## 对白回看与速度

回看保留最近 100 条完成的原文/译文，按提交时间排列，仅在内存中保留，退出清空。固定悬浮快速模式保留原有八条待译队列；原位/旁置每区最多 24 条待译项，另有至多两条由该区消费者取出等待或处理。所有区域共用最多两条 HTTP 请求和缓存。

默认快速采样 150ms、API 起始间隔 400ms；平台限额仍适用，429 冷却保留。瞬间且未采样到的文字不能恢复，公网 API 的生成耗时不能由显示模式消除。练习窗口的 0.8 秒自动对白可测试实际服务。

## 排查问题

左侧“诊断与日志”显示截图、OCR、文字判断、翻译服务、悬浮显示。日志带区域编号，临时区标记“临时”；`BLOCKS_LOCATED` 表示完成分段，`BLOCK_TRANSLATING`/`BLOCK_TRANSLATED` 表示独立请求和返回，`BLOCK_QUEUE_FULL`/`BLOCK_LIMIT` 表示积压或数量上限。401/403/402/429/404 分别检查密钥、权限/地区、余额、限流、模型/地址。

“检查识别”查看当前选区截图和原始文字，不请求翻译。“测试翻译服务”只发送固定句子，不经过截图/OCR。“导出诊断报告”包含最近最多 500 条元数据，不包含密钥、原文、截图、窗口标题或地址；回看内容不进入报告。日志在本机自动轮换。

设置、生词和加密密钥位于 `%LOCALAPPDATA%/LexiLens`。升级退出旧版、完整解压新版运行即可。云端使用自己的标准 API Key 与额度；OCR 模型已内置，Ollama 翻译模型需另行安装下载。
