# v0.5.0 验证记录

记录日期：2026-10-20。

- 80 项核心测试通过，零构建警告/错误。
- 首次识别之后，即使第二帧永不返回，快速模式也能完成第一句翻译。
- 故意延迟第一句，第二句先返回；两句均进入回看事件，旧结果不会覆盖新显示。
- 慢服务故障注入验证每区 8 条待译上限及 `SUBTITLE_QUEUE_FULL` 提示，停止能取消两条正在进行的请求。
- 验证两个区域可并行请求、相同文字只请求一次；云端最小起始间隔不再等待另一条响应正文。
- 旧单区配置迁移、多区数量/无效坐标/悬浮位置校验、区域名称不进入报告均通过。
- 桌面诊断真实截取两个不同练习句，用本地模拟 HTTP 服务返回不同译文，验证独立悬浮框、切换区域、穿透、位置保存和对白回看。原有实际 PaddleOCR/MyMemory、故障超时回退、取消、日志导出继续验证。
- 固定练习字幕的一次快速读取测得约 14ms（Windows OCR 已在诊断前文使用）；这是截图+OCR 的单次样本，不包含公网 API，也不代表其他字体/机器的延迟。发布包最终复测见本机 artifacts 的诊断 JSON。
- README 多区图、回看图来自受控练习帧和模拟译文，未使用真实账号 Key。

[速度与队列边界](PERFORMANCE.md)。本次未测试具体商业游戏、HDR、混合 DPI、所有平台真实 Key 或长期运行。手动多区域已实现，自动语义分组和自定义快捷键未实现。

- 桌面诊断通过真实 GDI → 独立子进程 PaddleOCR → MyMemory → 悬浮显示，报告确认实际引擎为 PaddleOCR。
- 故障注入令 OCR 子进程无限等待，验证超时终止、Windows OCR 恢复和 `OCR_TIMEOUT_FALLBACK` 日志；取消请求也终止子进程。
- 验证真实练习窗口在窗口目标枚举中可选，选择器绘制边界并返回有效区域；验证点击确认处理与手动框选入口均保留。实际用户鼠标跨屏交互仍需更多环境验证。
- 导出报告包含阶段与错误代码，不包含测试密钥或练习原文。渲染检查浅色主界面、平台配置、识别检查、选择器与诊断页。
- 未使用用户的实际游戏画面或智谱 Key；不能把已复现的等待触发条件当成所有现场故障的唯一根因。真实游戏、HDR、混合 DPI、其他 CPU 与长期运行继续待测。

## v0.3.0（2026-10-20）

- 64 项核心自动测试通过；新增 Responses 请求/响应、关闭服务端存储、只读取译文内容、拒绝截断响应、千问地区与密钥隔离、OCR 同行合并和段落次序。
- 发布版自包含 EXE 真实加载 PaddleOCR v5/CPU 原生库，完成固定练习句的 GDI 截图 → 本地增强 OCR → MyMemory 翻译 → 悬浮显示；没有依赖本机 .NET SDK 启动。
- 8 组固定合成字体样张的字符错误率为 Windows OCR 22.7%、增强 0.8%；仍有两个相似字母误识别。首次约 2.3 秒、后续样张约 0.6–0.8 秒，不能代表实际游戏或其他硬件；详见 [原始记录与测试方法](OCR.md)。
- 空白样张无文字输出。报告确认实际使用 PaddleOCR，没有退回 Windows OCR 后冒充增强测试。
- 26 个向导选项默认可见，快捷选择 DeepSeek/豆包、千问地区切换及跨地区密钥隔离通过。原有 DPAPI、删除密钥、悬浮穿透/截图排除继续通过。
- 验证 DeepSeek 官方根地址更新后仍能使用 v0.2 的已存密钥，且删除操作有效。
- 识别检查窗口渲染通过，仅展示固定生成样张；正常使用不保存或上传截图。文档界面图仅使用程序自身固定示例、虚构 Key 和模拟连接结果。

## 运行桌面诊断

```powershell
dotnet run --project src/LexiLens.App -- --diagnostics artifacts/diagnostics
```

诊断只截取自己创建的练习窗口，只向 MyMemory 发送练习文本，使用单独的临时配置目录，不加载现有生词本或设置。会输出 `report.json`，其中 `success` 汇总 OCR、截图、穿透和在线会话检查。需要可交互桌面、英语 OCR 和网络；不适合无桌面 CI。
