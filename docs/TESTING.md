# 第一阶段捕获与延迟验证（2026-10-30）

本轮以实际仓库的 `v0.6.0` 提交为审计起点，保留现有架构，增加 GDI/WGC HWND + 字幕 ROI 对照及单调时钟流水线记录。方法、事件口径、支持条件与证据缺口见 [CAPTURE_VALIDATION.md](CAPTURE_VALIDATION.md)；元数据统计脚本为 `scripts/summarize_capture.py`。

最终核心回归为 103 项通过，Release 构建零警告、零错误。四项旋转文字框几何回归和产品覆盖层检查记录在工程证据中；它们不构成游戏性能达标结论。

自包含单文件本机测试构建 `0.6.0-capture.1` 的工程捕获检查及同批真实游戏素材 Paddle 回放通过；便携检查未调用 HTTP，也未证明干净系统、混合 DPI 或所有游戏的兼容性。

下文 v0.6.0 及更早版本的测试均为历史记录。其固定练习句、合成字体、模拟 HTTP、单次耗时和布尔通过项，不能作为真实游戏回放、真实服务延迟或实际游戏帧时间证据。实际游戏 CER、完整句识别率、翻译准确率、各阶段 p50/p95、游戏帧时间、漏句及过期译文，在取得对应证据前均为未测，不填入达标数值。

本阶段执行结果以本轮输出目录的原始 JSONL、诊断报告及其汇总为依据，需区分工程检查、真实片段回放、实际游戏和真实服务，不合并成一个 `success` 结论。

本轮已执行的色块工程检查中，GDI/WGC 原生 ROI、RGB 一致性、移动/缩放、实际产品覆盖层截图排除、隐藏/裁剪结果不计有效显示、取消及目标关闭均通过；DPI 为 96→96，没有覆盖 DPI 改变。另完成色块的实际 Paddle 空结果回放，未发 HTTP。详见 [脱敏工程记录](benchmarks/capture-phase1-engineering.json)；这些结果不能替代游戏字幕或真实服务测试。

随后完成真实游戏菜单 ROI 的约 12 秒回放，以及实际 WGC/GDI 各 15 秒配合智谱 `glm-4.5-flash` 实网运行。已记录阶段 p50/p95、请求/取消、有效显示及过时修订计数；不是对白或过场测试。独立的修复前菜单抽样评估得到原始 OCR CER `32/612`、空间输出 CER `272/612`，暴露了分块行序错误；较早回放中名为 `ocrQuality` 的统计实际用了空间输出，本轮已拆分纠正口径。详见 [菜单测量元数据](benchmarks/capture-phase1-game.json)及方法文档。没有完整对白标注、显示录屏或游戏关闭/开启帧时间基线，漏句、过期译文、完整译文准确率和游戏帧时间仍未测。

修复 Paddle 旋转文字框映射后，同帧几何检查通过；完整素材的独立实时复测中，原始/空间输出均为 `27/612`（4.4118%，12 帧、0 帧完全匹配）。前后抽样帧不同，不把原始 OCR 数值变化归因于坐标修复。再次回放及 WGC/GDI 实网运行分别完成 4/4、4/4、2/2 请求，仍有迟到结果被拒及缓存显示；阶段与 HTTP 冷/热完整数据已另列，保留修复前证据。判断仍为部分验证，未验证短时对白/过场。

# v0.5.0 验证记录

记录日期：2026-10-20。

- 80 项核心测试通过，零构建警告/错误。
- 首次识别之后，即使第二帧永不返回，快速模式也能完成第一句翻译。
- 故意延迟第一句，第二句先返回；两句均进入回看事件，旧结果不会覆盖新显示。
- 慢服务故障注入验证每区 8 条待译上限及 `SUBTITLE_QUEUE_FULL` 提示，停止能取消两条正在进行的请求。
- 验证两个区域可并行请求、相同文字只请求一次；云端最小起始间隔不再等待另一条响应正文。
- 旧单区配置迁移、多区数量/无效坐标/悬浮位置校验、区域名称不进入报告均通过。
- 桌面诊断真实截取两个不同练习句，用本地模拟 HTTP 服务返回不同译文，验证独立悬浮框、切换区域、穿透、位置保存和对白回看。原有实际 PaddleOCR/MyMemory、故障超时回退、取消、日志导出继续验证。
- 固定练习字幕的一次快速读取测得约 14ms（Windows OCR 已在诊断前文使用）；这是截图+OCR 的单次样本，不包含公网 API，也不代表其他字体/机器的延迟。发布包最终复测见本机 artifacts 的诊断 JSON。
- README 多区图、回看图来自受控练习帧和模拟译文，未使用真实账号 Key。

[速度与队列边界](PERFORMANCE.md)。本次未测试具体商业游戏、HDR、混合 DPI、所有平台真实 Key 或长期运行。手动多区域已实现，自动语义分组和自定义快捷键未实现。

## 运行桌面诊断

```powershell
dotnet run --project src/LexiLens.App -- --diagnostics artifacts/diagnostics
```

诊断只截取自己创建的练习窗口，只向 MyMemory 发送练习文本，使用单独的临时配置目录，不加载现有生词本或设置。会输出 `report.json`，其中 `success` 汇总 OCR、截图、穿透和在线会话检查。需要可交互桌面、英语 OCR 和网络；不适合无桌面 CI。
